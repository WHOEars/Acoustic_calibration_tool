# Acoustic Calibration Tool

A real-time acoustic calibration and analysis tool developed in Python.

This application performs real-time FFT spectrum analysis and allow to create spectal power to dB AC using a standard microphone.

---

## 🧩 Features

- Real-time spectral display (dBFS)  
- Adjustable frequency range and smoothing  
- Manual and automatic peak detection  
- Save spectrum images with annotations
- Calibration table editor with preloaded reference values
- dB - AC regression calculation  

---

## ⚙️ Requirements

**Python 3.9 or later**

Install dependencies with:

`pip install numpy matplotlib sounddevice`

---

## ▶️ Run

`python calTool.py`
